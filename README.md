## ✨ Features

- 🔐 Firebase Authentication
- ☁️ Cloud Firestore Database
- 💰 Expense Tracking
- 📊 Interactive Dashboard
- 📈 Charts & Analytics
- 🎯 Budget Management
- 💵 Income Tracking
- 🤖 AI Financial Advisor

- 📄 PDF Export
- 📊 CSV Export
- 🌙 Dark Mode
- 📱 Responsive Design

```bash
npm install
npm run dev
```
